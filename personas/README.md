## 2. Handle-check procedure (the user does this; nothing is claimed available)

The three candidates per persona are in section 2.2 of each bible, and the platforms and order to check are listed in `HUMAN_TODO.md`, "Phase 3: handle and name checks". Procedure:

1. **Do not create accounts to test names, and do not park placeholder accounts.** Look the handle up as a public profile URL in a logged-out browser, or type it into the sign-up field and stop before submitting. No replacement or backup accounts, ever (`portfolio.md 6.2`). Never buy, trade or "snipe" a handle (platform terms, `platforms.md 4.1`).
2. **Check the primary platform first, then the secondary ones** in the order given in HUMAN_TODO. Facebook Page usernames are checked in the Page creation flow, not on a personal profile.
3. **Read the live field for the allowed characters and length.** The bibles recall that Instagram and Threads allow letters, numbers, periods and underscores, YouTube also hyphens, and Facebook Page usernames letters, numbers and periods only with no underscore. All of that is recalled and unverified.
4. **Search each handle string as a person's name** (Ground rule 2: no name modelled on a real person). Pinyin handles such as `licheng`, `jiehua`, `suisui` and `dengyixia` can match real given names.
5. **Record per candidate:** the date, the platform, free or taken, and anything similar that is taken. Ask the wife whether a "taken" account is an unrelated or confusable account.
6. **Prefer one handle on every platform** for one persona. If a platform forces a different one, record it for the link page.
7. **Pick the first free candidate in the bible's order** unless the wife's reading test or the TIPO search (HUMAN_TODO Phase 3 section) says otherwise, then tell Claude so the bible's section 2.2 can record the choice. A free handle is not trademark clearance.
8. **Instagram login limit:** the Instagram account switcher holds five accounts (`portfolio.md 2.6`). Instagram-login accounts needed by Wave 4 are 方寸, 色環, 規格 (primary) plus 步驟 and 接話 (Threads needs an Instagram login, unverified) and 轉乘 after its review, which is six. Use separate devices or the platform's own switching, never cloning tools or automation (Ground rule 9). This is a user decision, see section 6.
